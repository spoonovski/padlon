Propojit s GitHubem

Aby tlačítko mohlo spustit kontrolu, potřebuje jednou GitHub token. Uloží se jen v tomhle prohlížeči, nikam jinam se neposílá.

  1. Otevři nový fine-grained token.
  2. Expiration: klidně No expiration nebo 1 rok. Repository access: Only select repositories → tvoje repo.
  3. Permissions → Repository → Actions: Read and write. Nic dalšího.
  4. Generate token, zkopíruj ho a vlož sem.
